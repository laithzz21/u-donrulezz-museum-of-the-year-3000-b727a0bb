## Entry

One line, at most 200 characters — the museum label a museum in the year 3000 places next to an ordinary object from today:

> Plastic Fork (c. 2025): Humans stabbed food with this, threw it away after one meal, then bought a metal one that did the exact same thing. Scientists are still confused.

170 characters, one line.

## Run

```sh
python3 main.py
```

`main.py` validates the entry (single line, at most 200 characters), prints it to stdout, and writes it to `$MAKEFUN_OUTPUT_DIR/entry.txt`, else `$MAKEFUN_OUTPUT`, else `/tmp/u-donrulezz-museum-of-the-year-3000-b727a0bb/entry.txt`. It never writes into the repository directory.
